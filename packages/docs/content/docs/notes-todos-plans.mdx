# Project Notes, Todos & Plans

Each project has its own scratch space for notes, a todo list, and saved plans. They belong to the project, not to any one session, so they stick around as you move between sessions. Find them in the **Context** tab of the right sidebar (a dedicated tab on mobile).

## Notes

A free-form notes box for anything you want to remember about the project. It saves on its own as you type.

## Todos

A simple checklist. Add items, check them off, reorder them by dragging, and clear the finished ones.

Each todo has a **send** menu so you can hand it to the agent:

- send it to the current session
- start a new session with it
- start a new [worktree session](/worktrees/) with it (only when the project is a git repo)

## Plans

A place to keep longer plans as saved files. You can:

- import a plan from a Markdown or text file
- open a plan to read it in the side panel
- delete plans you no longer need

You should land back in the Context tab with your note saved, your todo checked, or your plan listed — that's how you know it took.

## Agents

Agents read and update the same notes, todos and plans through the project knowledge tool. Ask an agent to note a decision, add a todo, tick one off, or keep a plan up to date, and the change shows up in the panel as it happens. Notes an agent creates are marked as coming from an agent. When an agent writes a plan for you, it can open the plan in front of you, where you read it, comment on lines, and send it to a session. Plans are plain markdown files, so agents read and edit them like any other file. They start a plan with a short checklist of its steps and tick each one as they implement it, and an open plan picks the changes up within a couple of seconds, so its preview shows how far the work got.

An agent works on the project its session belongs to, worktrees included. If an agent changes a note or plan while you are typing in it, what you type is saved over the agent's change. Agents are asked to send the text they read along with a note or plan they replace whole; if it changed since, the write is refused and the agent reads it again.

The tool is on by default. Turn it off in **Settings → General → OpenChamber Tools** with **Project knowledge tool**. Like the other OpenChamber tools, it is only there when OpenChamber runs its own OpenCode server, so not with an external server or in the VS Code extension.
